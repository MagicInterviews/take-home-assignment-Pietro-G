# About The Project

For this take-home assignment you’ll be working on a community event management platform called **EventEase**. Users sign into their account where they can view and register for events. We’ve built out part of the functionality for you, so your task will be to make some improvements to the app.

This project uses the same technologies we use everyday at MagicSchool:

- [Next.js](https://nextjs.org/docs)
- [Supabase](https://supabase.com/docs/reference/javascript/initializing)
- [Radix UI](https://www.radix-ui.com/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Figma](https://www.figma.com/)

## Time Expectations

- We anticipate that the take home will take around `4-6 hours`, but it's completely fine if you need more or less time.
- We don't want you spending a whole day or more on the project because we respect your time and life outside of this process.

## AI Expectations

Here at MagicSchool, we wholly support the use of AI assisted technologies when producing software solutions. As such, we can generally tell if your submission was "Vibe Coded". Though not against the rules, we expect that your solution _works_ and does not contain a myriad of AI generated artifacts. Be mindful of what you submit!
