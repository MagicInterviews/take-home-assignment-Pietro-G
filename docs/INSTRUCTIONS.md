## Project Tasks

While working on this project keep these things in mind:

- **Next.js App Router:** we utilize Next.js App Router at MagicSchool and are working to implement best practices
- **Code Quality & Completeness:** we want you to show off your coding abilities while also completing the tasks at hand
- **TypeScript:** we care strongly about types so take every opportunity to improve the types in this project
- **Responsive Design:** the provided Figma file does not include responsive designs - ensure your solution is functional at all screen sizes

Here is the [figma design](https://www.figma.com/design/KJSk2nmg0Se0QxbvTlwh1E/Full-Stack-Take-Home?node-id=0-1&t=CmyLqqj0GTqjNCXb-1) you can reference while you're implementing your tasks.

## Requirements

Please complete the following tasks. Consider this as "Acceptance Criteria" from a Product Team.

1. **Search/Filters Implementation:**
    - There’s a search bar on the `/events` page, but it currently doesn’t do anything
    - Implement server-side search functionality that allows users to search via event title at the very minimum, but feel free to also add in support for searching on other event fields
    - Implement a filter that would allow users to search for "Registered" and "Not Registered" events. There's no figma guidelines for this, so implement it visually however you see fit
    - If no results are found, display a “No events found” message similar to the one in the [figma designs](https://www.figma.com/design/KJSk2nmg0Se0QxbvTlwh1E/Full-Stack-Take-Home?node-id=0-1&t=CmyLqqj0GTqjNCXb-1)

1. **Styling:**
    - We’ve provided you with the core flow, but left it unstyled.
    - Restyle the app to match the provided [figma design](https://www.figma.com/design/KJSk2nmg0Se0QxbvTlwh1E/Full-Stack-Take-Home?node-id=0-1&t=CmyLqqj0GTqjNCXb-1)
